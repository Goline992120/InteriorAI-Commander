# InteriorAI Commander 🚀

Hệ thống quản lý và tự động hóa nội thất thông minh, kết hợp Telegram Bot và sức mạnh của AI.

## 🛠 Tính năng chính
- **Telegram Automation**: Tự động hóa tiếp nhận và xử lý yêu cầu khách hàng từ Telegram.
- **AI Analysis**: Tích hợp OpenAI để phân tích nhu cầu nội thất, tư vấn thiết kế và phân loại khách hàng tiềm năng.
- **FastAPI Backend**: Hệ thống vận hành ổn định, tốc độ cao, sẵn sàng mở rộng.
- **Thiết kế tối ưu**: Tối ưu cho quy trình làm việc trong ngành nội thất (PVC, lam sóng, charcoal bamboo).
